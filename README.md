# Saylavy statistics dashboard

Investor-facing statistics dashboard for the Saylavy app.

**Live:** https://eugenazxa.github.io/Saylavy-statistics-/

Everything lives in `index.html` - markup, CSS and JavaScript are all inline. There is no
build step. Edit it, commit, push, and GitHub Pages serves the new version in under a
minute. App screenshots are in `screenshots/`.

**Before changing anything, read [NOTES.md](NOTES.md).** It covers the open items (one of
which is a counter that adds two sign-ups a day on its own), which numbers are measured
rather than estimated, where each figure lives in the file, and the layout traps already
hit and fixed.
